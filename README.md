## De novo design of peptides localizing at the interface of biomolecular condensates
All code and input files for the molecular dynamics (MD) simulations, machine learning (ML), and mixed-integer linear programming (MILP) performed in the paper. 

### Contents
| Path | Contents |
|------|----------|
| `MD_simulations/` | all LAMMPS/GROMACS/OpenMM input files + Python preprocessing/postprocessing scripts |
| `ML_MILP/` | Example active learning iteration |

### Key dependencies

 * LAMMPS version 2nd of August 2023
 * GROMACS 2021.4
 * OpenMM 8.2.0
 * PLUMED 2.8.0
 * Python 3.11.6 (Key dependencies: pytorch 2.3.1, scikit-learn 1.5.1, pyomo 6.7.3, omlt 1.1)
 * Gurobi 12.0.1
 
### Instructions
The folder `MD_simulations` contains the inputs and results of all molecular simulations performed in this study. Individual simulation files can be generated by running the script `create_X_sim_files.py` in the corresponding folder.

The `ML_MILP` folder contains all code for a single iteration of the active learning loop using example data. This includes:  
- training the surrogate model (`ML_MILP/Step1_train_ANN.py`)  
- identifying optimal sequences (`ML_MILP/Step2_MILP.dat`)  
- postprocessing (`ML_MILP/Step3_Postprocessing.py`), which generates a new list of sequences to be passed to the molecular dynamics simulations, producing data for the next iteration.

The required Python packages can be installed with the following command (runtime ~1 min):  

`pip install torch==2.3.1 scikit-learn==1.5.1 pyomo==6.7.3 omlt==1.1 numpy==1.26.4 matplotlib==3.9.0 onnx==1.16.1`

Execution time for all scripts is short, except `ML_MILP/Step1_train_ANN.py`, which takes ~10 min. Scripts have been validated on Windows 10.

Molecular dynamics simulations and `ML_MILP/Step2_MILP.dat` should ideally be run on a cluster. In addition to the Python setup, [LAMMPS](https://docs.lammps.org/Manual.html) and [Gurobi](https://www.gurobi.com/) must be installed. Running the MARTINI / CALVADOS simulations requires [GROMACS](https://www.gromacs.org/) / [OpenMM](https://openmm.org/). For generating contact maps, a [PLUMED](https://www.plumed.org/) installation is needed. Execution of a homotypic interaction simulation takes ~1 h (1 core each), interface partitioning simulation ~16 h (2 cores each), and MILP optimization for the provided example data `ML_MILP/Step2_MILP.dat` takes ~20 min (32 cores). Depending on the iteration, optimizer convergence time may increase to several hours. Scripts have been tested on the Euler computing cluster at ETH Zurich (Ubuntu 22.04).
